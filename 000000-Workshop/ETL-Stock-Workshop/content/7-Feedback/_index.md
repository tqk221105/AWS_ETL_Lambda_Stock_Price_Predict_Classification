# Sharing and Feedback

This section reflects on my experience with the First Cloud AI Journey learning environment and the process of delivering the AWS ETL stock project. The comments focus on learning support, project relevance, skill development, teamwork, and expectations for future learning opportunities.

## Overall evaluation

### 1. Learning and working environment

The project-based environment encouraged independent research, technical discussion, and experimentation. Building a real system helped me develop habits around task planning, source control, validating changes before integration, and taking responsibility for technical decisions.

### 2. Mentor and facilitator support

The guidance emphasized project scope, architectural thinking, and technical-report presentation while encouraging me to investigate problems before requesting a complete solution. This approach improved my self-learning ability and helped me understand the reasons behind each technical decision.

### 3. Relevance to the academic major

The project combined Python programming, data processing, distributed systems, cloud computing, machine learning, APIs, and user-interface development. Academic concepts became more concrete through system design, data-quality rules, model evaluation, and service deployment.

### 4. Learning and skill-development opportunities

I gained practical exposure to AWS Lambda, Amazon S3, SQS, EventBridge, API Gateway, ECR, Docker, Polars, Parquet, XGBoost, Hugo, and technical documentation. I also improved my ability to read documentation, explain architecture, report problems, present results, and coordinate work across modules.

### 5. Team culture and collaboration

Team members supported one another during development and review, especially when a change in the data layer affected the model or dashboard. The project demonstrated the importance of documenting inputs, outputs, configuration, and module ownership to reduce integration conflicts.

### 6. Learning resources and program support

The reference materials, workshop roadmap, mentor guidance, and opportunities to review technical work provided a useful foundation for completing the project. They also helped connect university knowledge with practical AWS implementation.

## Additional questions

### What was the most satisfying part of the project?

The most satisfying result was connecting separate components into one end-to-end flow: data is collected, validated, transformed, used for model training, served through an API, and displayed on a dashboard. Solving the Lambda timeout problem with SQS Fan-Out was also a meaningful technical achievement.

### Would I recommend the program to friends or other students?

Yes. I would recommend the program because it offers opportunities to learn through practical AWS projects across several areas. The proposed topics include DevOps and CI/CD, Cloud Operations and high availability, cloud application development, Infrastructure as Code with AWS CDK, and end-to-end Machine Learning with SageMaker. This range shows that FCAJ can support different career interests, from software and infrastructure to AI/ML, while helping participants understand how these areas work together in a cloud system.

## Suggestions and expectations for the company

- Continue offering project topics from multiple technical areas so participants can select a direction that matches their interests while still learning from other teams.
- Organize short cross-topic sharing sessions where DevOps, Cloud Operations, Application Development, Infrastructure as Code, and Machine Learning teams present their architectures and lessons learned.
- Maintain regular mentor checkpoints to help participants validate scope, architecture, security, cost, and project progress.
- Create more opportunities for product demonstrations and technical reviews so participants can practice presentation skills and receive practical feedback.
- Support participants who want to connect AI/ML work with deployment, monitoring, APIs, and automated infrastructure instead of treating the model as an isolated component.

## Future participation

I would like to continue participating in FCAJ activities because the program provides opportunities to learn across multiple fields. My primary interest is AI and Machine Learning on AWS, especially data preparation, SageMaker training, model deployment, monitoring, and pipeline automation. At the same time, learning more about DevOps/CI-CD, Cloud Operations, application development, and Infrastructure as Code would help me become an AI Engineer who can understand and deliver a complete production system rather than focusing only on model development.
